# Bayan (بيان)
AI-powered platform to interact with books using voice.

## Features
- Upload PDF books
- Ask questions about the content
- Voice interaction (Arabic supported)

## Tech Stack
- Next.js + TypeScript
- MongoDB
- Vapi (Voice AI)
- Tailwind CSS

## Demo
https://bayan-brown.vercel.app

## Note
This is an MVP/demo version focused on experimentation and Arabic support.
